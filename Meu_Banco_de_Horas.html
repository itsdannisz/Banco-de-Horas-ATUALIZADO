Configurar a nuvem com Apps Script
  1. No Drive, crie um arquivo JSON com o conteúdo {"e":[],"rs":{}} e copie o ID da URL.
  2. Crie um projeto em script.google.com e cole o código abaixo.
  3. Nas propriedades do script, configure BH_FILE_ID com o ID do arquivo e BH_PASSWORD com uma senha forte.
  4. Implante como aplicativo da Web, executando como você e com acesso “Qualquer pessoa”. Autorize o acesso ao seu arquivo.
  5. Cole a URL terminada em /exec acima. Para atualizar uma implantação existente, publique uma nova versão.

O script verifica a senha e combina alterações com uma trava de gravação.
